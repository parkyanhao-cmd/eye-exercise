# 눈운동 · 目の運動 · Eye Exercise · 眼部运动

[한국어](#한국어) · [日本語](#日本語) · [English](#english) · [简体中文](#简体中文)

## 한국어

AI 시대, 프로그래머의 눈물은 누가 이해할까요?
코드는 계속 만들어져도, 당신의 눈에는 휴식이 필요합니다. 잠깐 화면에서 눈을 떼고 쉬어 가세요.

### 바로 실행

압축을 풀고 **index.html**을 브라우저로 엽니다. 별도 설치·빌드·로컬 서버가 필요 없습니다.

1. 언어, 색상, 종료 기준, 이동 경로, 속도, 아이콘 크기를 선택합니다.
2. **시간**은 20·40·60초, **횟수**는 1·5·10·15·20·30·50회 중 선택합니다.
3. **시작**을 한 번 누르면 설정 화면이 숨겨지고 운동 전용 화면에서 바로 움직입니다.
4. **일시정지 / 계속**으로 제어합니다. 일시정지한 시간은 진행에 포함되지 않습니다.
5. **종료 또는 Esc**를 누르면 설정 화면으로 돌아갑니다. 완료 후 **다시 시작**하거나 **설정으로** 돌아갈 수 있습니다.

횟수는 선택한 경로를 한 바퀴 돌아 출발점에 복귀했을 때 1회입니다. 경로 길이와 속도에 따라 한 바퀴의 시간이 달라집니다. 모드 1은 원본의 교차 순서입니다. 모드 2는 좌상 → 좌하 → 우상 → 우하 → 좌상입니다. 모드 3·4는 마지막 우하에서 좌상으로 돌아가는 궤적 선을 표시하지 않습니다. 반복 시 시작점으로 돌아가는 움직임은 유지합니다.

Space는 일반 화면에 초점이 있을 때 일시정지/계속입니다. 버튼에 초점이 있으면 해당 버튼을 실행합니다. 입력창에서는 기본 키 동작을 유지합니다. 탭 전환은 자동 일시정지가 아닙니다. 쉬는 동안은 일시정지를 누르세요. 새로고침하면 설정이 초기화됩니다.

### 색상과 아이콘

- **클린 블루**: 밝은 회색·흰색 바탕에 파란색 버튼.
- **미드나이트**: 어두운 네이비 바탕에 밝은 파란색 버튼.
- **소프트 라벤더**: 옅은 보라색 바탕에 보라색 버튼.
- 직접 제작한 컬러 SVG **12종**: 행성·꽃·로켓·나비·수박·물고기·사탕·무지개·버섯·별·열기구·고양이.
- 아이콘 변경 방식을 선택할 수 있습니다. **한 바퀴마다 변경**은 한 바퀴 동안 같은 아이콘을 유지하고 다음 바퀴에 변경합니다. **이동마다 랜덤**은 기존 방식입니다. 시간·횟수 모드 모두 적용되며, 변경 시 같은 아이콘이 연속해서 나오지 않습니다.

### GitHub Pages 게시

1. GitHub 저장소를 만들고, 이 폴더 안의 파일을 저장소 **최상위**에 업로드합니다. ZIP 자체를 올리지 마세요.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
3. **main / (root)**를 선택하고 저장합니다.
4. 배포 후 Pages 화면에 표시된 HTTPS 주소를 공유합니다. Pages 사용 가능 여부는 계정·저장소 정책에 따라 다릅니다.

이 패키지는 GitHub에 자동으로 업로드하거나 게시하지 않습니다. 외부 사이트와 로컬 HTML 모두 금지된 회사에서는 승인된 사내 웹 게시를 요청하세요. 보안 정책을 우회하지 않습니다.

## English

In the age of AI, who understands a programmer’s tears?
The code keeps coming. Your eyes still need a break. Look away from the screen for a moment. Take a breath.

Extract the ZIP and open **index.html** in a browser. No installation, build or local server is needed. Settings and exercise are separate screens. Choose time (20/40/60 seconds) or repetitions (1/5/10/15/20/30/50), then press Start once. A repetition completes the selected path and returns to its starting point. Paused time does not count. End or Esc returns to settings; after completion you can start again.

Three themes and 12 original colorful SVG icons are included. Choose one icon per repetition (changes at the next lap), or random changes on every move. Both apply in time and repetition modes, without immediate repeats. Space pauses/resumes when focus is outside controls; a focused button retains its normal keyboard behavior. Switching tabs does not pause. Reloading resets settings.

GitHub Pages: upload the folder contents to the repository root, choose Settings → Pages → Deploy from a branch → main / (root), then share the displayed HTTPS URL. Account/repository policy determines availability. This package does not publish itself. For managed company devices, use an approved hosting or local-file method.

## Privacy / 보안 / プライバシー / 隐私

All CSS, JavaScript, translations and icons are inside `index.html`. No external libraries, fonts, analytics, cookies, local storage or permission requests are used. The app has no data-transmission code. HTTPS hosting still creates normal server requests, which may expose ordinary network metadata to the host. A Content Security Policy blocks external connections/resources. Company browser policy may block local files or JavaScript.

## Editing

| Location in index.html | Purpose |
|---|---|
| CSS `:root` and theme overrides | Background, text, border and accent colors |
| `.wrap`, `.grid`, `.session`, `.stage` | Settings layout and viewport-sized exercise screen |
| `translations` / `additions` | Korean, Japanese, English and Chinese labels |
| `shapes` | Twelve original inline SVGs |
| `path(mode)` | Movement orders; mode 2 is top-left → bottom-left → top-right → bottom-right |
| `beginSession()` | Show exercise screen before measuring; start a fresh animation |
| `position(ms)` | Move on first step, then advance along the path |
| `session.cycleMs`, `session.totalMs` | Time versus repetition completion |
| `togglePause()`, `endSession()` | Pause/resume and return to settings |

For direct file execution, keep scripts/translations embedded rather than loading JSON through fetch.
